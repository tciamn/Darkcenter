## SSH Access

The incoming admin must generate their own SSH key on their own hardware and have it added to the VPS by the primary admin:

```bash
# Primary admin adds second admin's public key on the VPS
echo "<second-admin-public-key>" >> /root/.ssh/authorized_keys
```

Primary admin connects via:
```bash
ssh -i ~/.ssh/hetzner_futurelabs root@2.29.7.30
```

Only one admin currently. Per Future Labs policy, ≥ 2 admins with independent access are required.

The incoming person receiving this handoff IS the second admin. Steps:
1. Generate SSH key on your own hardware
2. Primary admin adds your public key to `/root/.ssh/authorized_keys`
3. Primary admin creates your Mastodon account: see `deploy/mastodon/README.md` — Second Admin Setup

## Admin Recovery

If locked out of https://futurelabs.social:

```bash
ssh -i ~/.ssh/<your-key> root@2.29.7.30
cd /opt/mastodon
docker compose run --rm web bin/tootctl accounts modify aasim --reset-password
```

Prints a temporary password. Log in, change password immediately, save to password manager.

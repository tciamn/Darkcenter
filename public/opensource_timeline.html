A Living History

THE OPEN
SOURCE TREE

From free software philosophy to the infrastructure of civilization
1983
GNU Project

Richard Stallman announces GNU

Stallman posts to net.unix-wizards declaring the goal of building a complete free Unix-compatible OS. The seed of free software philosophy is planted — software as shared human knowledge, not proprietary commodity.

1985
Free Software Foundation

FSF founded & GNU Manifesto

The Free Software Foundation is established to support the GNU project. The GNU Manifesto articulates the four freedoms: use, study, modify, distribute. A moral and political framework for software freedom is codified.

1989
Licensing

GNU GPL v1 released

The first General Public License introduces "copyleft" — using copyright law to guarantee software freedom. Any derivative work must remain free. A legal innovation that would shape open source law for decades.

1991
⎇ Linux Kernel Branch
Linux Kernel

Linus Torvalds releases Linux 0.01

"I'm doing a (free) operating system (just a hobby, won't be big and professional like gnu)." — A 21-year-old Finnish student posts to comp.os.minix. The kernel that would power the internet, Android, and supercomputers is born.

GNU / Linux

GNU tools + Linux kernel unite

The GNU userland tools combined with the Linux kernel form a complete, freely distributable operating system. The GNU/Linux combination becomes the foundation of modern open source infrastructure.

1993 – 1994
⎇ Open Web Branch
Open Web

Debian & Slackware: first distros

The first Linux distributions package the GNU/Linux system for everyday users. Debian — founded on a Social Contract with the free software community — establishes democratic governance models that influence open source projects to this day.

Open Web

Mosaic & open web standards

The NCSA Mosaic browser is released freely, catalysing the World Wide Web. CERN releases the web protocol code into the public domain. Open standards — not proprietary walled gardens — become the web's foundation.

1995 – 1997
LAMP Stack

Apache, MySQL, PHP, Perl emerge

The open source LAMP stack (Linux, Apache, MySQL, PHP/Perl) quietly becomes the engine of the commercial web. Wikipedia, early e-commerce, and millions of sites run on freely shared code — demonstrating open source's economic viability.

Collaboration

Eric Raymond: The Cathedral & the Bazaar

Raymond's landmark essay — "given enough eyeballs, all bugs are shallow" — articulates the bazaar model of open, distributed development vs. the cathedral model. It shifts mainstream perception of open source from hobbyist to engineering methodology.

1998
⎇ Commercial Adoption Branch
OSI Founded

"Open Source" coined — OSI born

Christine Peterson coins "open source" as a pragmatic alternative to "free software." Bruce Perens and Eric Raymond found the Open Source Initiative. The OSD (Open Source Definition) provides the canonical license framework adopted globally.

Mozilla

Netscape open-sources Navigator

Netscape releases the Navigator browser source code — the first major commercial software company to go open source. The code becomes Mozilla, then Firefox. A watershed moment: open source is not just philosophy, it's a competitive strategy.

2000 – 2004
Linux Distros

Red Hat IPO & Ubuntu (2004)

Red Hat's 1999 IPO proves open source can be a billion-dollar business. Ubuntu launches in 2004, bringing Linux to mainstream desktops with a community-centred, accessibility-first philosophy. "Linux for human beings."

Creative Commons

Lawrence Lessig founds Creative Commons

CC licences extend the open source idea beyond software — to music, art, education, science. Wikipedia adopts CC licensing. Open knowledge becomes a movement, not just open code. The "free culture" era begins.

2005 – 2008
Version Control

Git released by Linus Torvalds

Git is born out of necessity after a licensing dispute with BitKeeper. Distributed version control transforms how humanity collaborates on code — no single point of failure, no central authority. The infrastructure of open source collaboration is reinvented.

Android

Android released (Linux-based)

Google releases Android — an open source mobile OS built on the Linux kernel. Within five years it will power billions of devices worldwide. Open source becomes the dominant platform for mobile computing, reshaping global digital access.

2008 – 2010
⎇ Cloud & Infrastructure Branch
GitHub

GitHub launches (2008)

GitHub puts Git on the web with a social layer — forking, pull requests, issues, profiles. Open source becomes networked and discoverable. Within a decade, 100M+ repositories will be hosted publicly. The commons of code becomes a planetary resource.

Node.js / npm

Node.js & the package ecosystem era

Ryan Dahl releases Node.js (2009) — JavaScript on the server. npm emerges as a package registry. The era of reusable, shareable micro-packages begins. Open source shifts from large projects to modular ecosystems of interdependent libraries.

2011 – 2013
OpenStack

OpenStack & cloud-native open source

NASA and Rackspace release OpenStack — open source cloud infrastructure. Docker launches in 2013, containerising applications. Open source becomes the default substrate of cloud computing. AWS, Azure and GCP all run on Linux and open source stacks.

Corporate Strategy

Microsoft joins the open source world

A company that once called Linux "a cancer" open-sources .NET (2014) and joins the Linux Foundation. The shift signals complete corporate normalisation of open source. "Love" replaces "extinguish" in Microsoft's open source strategy.

2014 – 2017
Kubernetes

Kubernetes open-sourced by Google

Google releases its internal container orchestration system as open source (2014). The CNCF (Cloud Native Computing Foundation) is founded. Kubernetes becomes the universal platform for deploying software — open source governs planetary-scale infrastructure.

Supply Chain

Log4Shell & supply chain reckoning

A critical vulnerability in the ubiquitous Log4j library (2021) exposes that the open source supply chain underpinning global commerce has no central steward. The US government, Linux Foundation and major corporations begin investing in open source security as critical infrastructure.

2018 – 2020
⎇ Open Source AI Branch
Sustainability

GitHub acquired by Microsoft ($7.5B)

Microsoft acquires GitHub (2018). Open source's central commons is now owned by a corporation. The tension between open contribution and commercial control resurfaces. GitLab and Codeberg emerge as alternatives. The question of who governs the commons remains unresolved.

Open AI Research

TensorFlow, PyTorch & open ML

Google open-sources TensorFlow (2015); Facebook releases PyTorch (2016). These frameworks democratise deep learning research. The open publication norm at NeurIPS, ICML and arXiv means AI breakthroughs flow freely across the global research community.

2021 – 2023
Open LLMs

Meta releases LLaMA; Hugging Face grows

Meta releases the LLaMA large language model weights (2023). Hugging Face becomes the "GitHub of AI" — hosting hundreds of thousands of open models and datasets. Open source AI challenges the dominance of closed frontier models, democratising access to transformative technology.

Sustainability

Open Source & climate tech convergence

Open source energy modelling (PyPSA), climate data (Open Climate Fix), and sustainable agriculture tools proliferate. The Linux Foundation launches LF Energy. Open source becomes critical infrastructure for the energy transition — shared tools for shared planetary challenges.

2024 – 2025
OSI AI Definition

OSI releases Open Source AI Definition

The Open Source Initiative publishes the first formal definition of "open source AI" — requiring access to training data, model weights, and inference code. A new frontier in the decades-long debate about what "open" truly means is drawn.

Governance

EU Cyber Resilience Act & open source

The EU CRA (2024) introduces security obligations for software — triggering fierce debate about liability for open source maintainers. Governments increasingly treat open source as critical infrastructure, demanding accountability alongside freedom.
